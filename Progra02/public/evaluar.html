Evaluación de relevancia

Buscá una consulta y marcá cada resultado según qué tanto responde a lo que se buscaba: 0 no relevante, 1 relevante, 2 muy relevante. Las notas se guardan una por documento y consulta: podés cerrar la página y continuar después.

¿Quién evalúa?

Sin nombre: podés mirar los resultados, pero para marcar necesitás identificarte.

Cómo se evalúa

  • Elegí una consulta de la lista (son búsquedas reales del grupo) o escribí una propia.
  • Marcá cada resultado. La misma nota otra vez borra el juicio, así podés corregir.
  • Con el teclado, 0, 1 y 2 marcan el primer resultado pendiente.
  • Cuando termines, la página de métricas se recalcula con tus juicios.
