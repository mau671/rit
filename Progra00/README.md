# Progra00

Proyecto del arañador para el curso IC-8060.

La especificación pide dos implementaciones para la misma necesidad de
información:

| Carpeta | Implementación |
|---|---|
| `arañador/` | Con bibliotecas existentes: Python, Scrapy, Trafilatura y SQLite |
| `propio/` | Propia, sin bibliotecas de arañado, con hilos y descarga concurrente |

Cada carpeta es un proyecto independiente con su propio `pyproject.toml`,
README, pruebas y configuración local `.env`.
