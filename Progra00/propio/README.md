# Implementación propia

Espacio para la implementación del arañador sin bibliotecas de arañado.

Debe cumplir los mismos requisitos que `../arañador/`:

- Leer las mismas semillas o una lista equivalente.
- Soportar hilos y descarga concurrente.
- Implementar las políticas documentadas.
- Guardar texto limpio y metadatos.
- Mantener bitácora de recorrido.
- Respetar límites de cortesía y `robots.txt`.

Cada implementación mantiene su propio `pyproject.toml`, README, pruebas y
`.env.example`.
